# Зерно — интернет-магазин кофе

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

Учебный многостраничный HTML/CSS-сайт интернет-магазина свежеобжаренного кофе и аксессуаров для заваривания. Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

## Технологии

- HTML5
- CSS3

## Как посмотреть проект

Открыть файл `index.html` в браузере.
