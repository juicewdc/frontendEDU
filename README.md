# Зерно — интернет-магазин кофе

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

В проекте реализован многостраничный HTML/CSS-сайт интернет-магазина свежеобжаренного кофе и аксессуаров для заваривания. Проект выполнен в рамках дисциплины «Фронтенд и бэкенд разработка» без CSS-фреймворков.

## Ссылка на опубликованный проект

## Обязательные страницы

| Страница | Содержание |
| --- | --- |
| `index.html` | главная: hero-блок, преимущества, популярные товары, шаги заказа, отзывы |
| `catalog.html` | каталог: шесть карточек товаров, категории, блок фильтров |
| `product.html` | карточка товара: изображение, описание, цена, таблица характеристик, кнопка заявки |
| `order.html` | форма оформления заявки |
| `contacts.html` | контакты, режим работы, форма обратной связи |

## Используемые технологии

- HTML5: семантические теги `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`, а также `dialog`, `details`, `figure`, `table`
- CSS3: переменные в `:root`, Flexbox, CSS Grid, состояния `:hover`, `:focus-visible`, `:disabled`, `:user-invalid`, селектор `:has()`
- БЭМ-именование классов: `site-header__logo`, `product-card__title`, `product-card--unavailable`, `button--secondary`
- Позиционирование: `sticky` (шапка, фильтр каталога, боковая колонка заявки), `relative` и `absolute` (бейджи на карточках, блок статистики в hero), `fixed` (кнопка «Наверх», сообщение об отправке), `z-index`
- JavaScript — только минимальная логика в `js/main.js`: открытие и закрытие модального окна, сообщение после отправки формы, подстановка товара в форму заявки

## Как посмотреть проект

1. Открыть опубликованную версию по ссылке GitHub Pages.
2. Либо скачать репозиторий и открыть файл `index.html` в браузере. Сборка и установка зависимостей не требуются.

## Самостоятельные доработки

- Собственная тема и визуальное оформление: магазин кофе, тёплая палитра, собственные SVG-иллюстрации товаров
- Дополнительные страницы: пять страниц товаров помимо `product.html` и страница `delivery.html` с таблицей способов доставки и блоком частых вопросов на `details`
- Карточки товаров: бейджи «Хит», «Новинка», «Скидка», категория, характеристики, старая цена, статусы наличия, модификатор `product-card--unavailable` с неактивной кнопкой
- Фильтр каталога по категориям без JavaScript — через радиокнопки и селектор `:has()`; фильтр закреплён при прокрутке
- Навигация: хлебные крошки на внутренних страницах, якорные ссылки в подвале, блок «С этим товаром смотрят», фиксированная кнопка «Наверх»
- Форма заявки: группы полей `fieldset`, выбор помола и способа доставки, подсказки, подсветка неверно заполненных полей, сообщение об отправке, автоматический выбор товара при переходе со страницы товара
- Модальное окно быстрой заявки на `dialog`: название товара подставляется из карточки, окно закрывается кнопкой, клавишей Esc и щелчком по затемнению
- Блоки отзывов и шагов заказа на главной
- Доступность: видимый фокус у всех интерактивных элементов, `label` у каждого поля, `aria-label` у навигаций, `aria-current` у текущей страницы, учёт `prefers-reduced-motion`
- Базовые медиазапросы, чтобы сетки не ломались на узких экранах
